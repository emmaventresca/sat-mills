# tools/

Scripts that built the decks in `data/` and `decks/`.

## A note on sourcing

These decks were built by mining College Board's question bank for **facts** —
which vocabulary words appear, which transitions are tested, how items are
distributed across skills and difficulty levels. Facts are not copyrightable.

**Every definition, example sentence, method card, strategy card and practice
sentence in this repository was written for it.** No College Board passage,
question, answer choice, rationale or answer key is reproduced anywhere here.
All 882 cards are original.

The retrieval script itself is deliberately **not published**. College Board's
educator terms prohibit scraping or data-mining their services, and publishing
a working how-to for it is downside with no upside. It stays on the machine
that used it.
